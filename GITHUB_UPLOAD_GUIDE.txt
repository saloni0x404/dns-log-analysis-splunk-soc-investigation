RECOMMENDED METHOD: UPDATE YOUR EXISTING LOCAL CLONE
----------------------------------------------------
1. Extract this ZIP somewhere convenient.
2. Open File Explorer and locate your EXISTING local repository folder.
   It should contain a hidden .git folder.
3. Copy the CONTENTS of the extracted dns-log-analysis-splunk folder into
   your existing repository folder. Allow Windows to replace matching files.
   Keep the existing .git folder untouched.
4. Open Git Bash in the existing repository folder.
5. Run the commands below, one by one.

COMMANDS (Git Bash)
-------------------
    git status
    git remote -v
    git branch --show-current

The remote should point to your existing GitHub repository. If it does not,
stop and check the URL before continuing.

Review what will be committed:
    git status --short
    git diff --stat

Safety check — this should return no tracked raw dataset:
    git ls-files | grep -iE '(^|/)dns\.log$'

Stage, review, commit, and push:
    git add -A
    git status
    git diff --cached --stat
    git commit -m "chore: professionalize DNS SOC investigation repository"
    git push

If Git says "nothing to commit", the copied files are identical to the current
repository. If push is rejected because the remote has newer commits, do not
force-push. Run:
    git pull --rebase
    git push

WINDOWS COMMAND PROMPT ALTERNATIVE
----------------------------------
For the safety check in CMD:
    git ls-files | findstr /i "dns.log"

The other Git commands are the same.
